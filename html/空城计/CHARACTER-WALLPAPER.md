# Q弹人物壁纸

在播放器“设置 → HTML 桌面背景”中选择 `character-wallpaper.html` 并启用。
HTML、`bg.png` 和人物图片放在同一个文件夹即可，最多显示 10 个人物。
“同一个文件夹”指所选 HTML 文件的目录。没有识别到图片时，页面会显示当前查找目录。

```text
character-wallpaper.html
bg.png
rw1.png
rw2.png
...
rw10.png
```

`rw1` 为中央前方的大人物，`rw2` 到 `rw10` 为后排小伙伴。缺少的编号自动跳过；
若没有 `rw1`，最小编号的人物会作为大人物。支持 PNG、WebP、GIF、JPG、JPEG、AVIF、SVG
以及不带扩展名但可被浏览器识别的图片；同一个编号有多个文件时按上述顺序优先使用。
推荐透明背景的 PNG / WebP，人物脚底靠近图片底边，避免画布空白造成悬空。

页面每 15 秒寻找新增人物，不必修改 HTML。替换已加载的图片后，重新启用壁纸或重启播放器。
只有实际找到的图片才会显示，缺失图片不会显示破图占位。

动画参照录屏：脚底固定，人物压扁、向上拉长、回落再弹一下。
当前布局针对“空城计”建筑背景：大人物站在中央庭院，其他人物较小、位置较高、位于其后方；
背景保留完整构图，默认不旋转。歌名和歌手以较小字号放在左上方天空，当前歌词及翻译
放在底部石板路上，使用米白文字和浅金色高亮。实际播放通过播放器的 `musicplayer.audio`
消息驱动；暂停和停止后形变回到静止状态。系统开启“减少动态效果”时人物保持静止。

用普通浏览器打开时可以点击右下角“预览弹跳”，或在地址后加 `?demo=1`。
预览节拍只用于查看动画，不会播放声音；在播放器中始终使用实际音频数据。
HTML 里的 `OPTIONS` 集中提供以下调整项（位置和尺寸均为屏幕比例）：

- `heroX`：大人物水平位置，默认 `.52`；减小向左、增大向右。
- `heroGround`：大人物底边位置，默认 `.835`；减小向上、增大向下。
- `heroHeight`：大人物形变前的高度，默认 `.26`。
- `rowStart` / `rowEnd`：后排左右边界，默认 `.29` / `.75`。
- `rowGround`：后排底边位置，默认 `.755`。
- `companionHeight`：小人物最大高度，默认 `.11`；人数较多时自动缩小以留出弹跳间距。
- `background`：背景文件名，默认 `bg.png`；可改成同目录内的其他图片名称。
- `amplitude`：弹跳力度，默认 `1.15`；`tilt`：整体倾斜角度，默认 `0`。

歌名和歌词的位置、字号分别在 CSS 的 `.song`、`.title`、`.artist`、`.lyrics`、`.current` 中调整。

项目根目录也提供一份可直接选择的 `character-wallpaper.html`，使用根目录现有的 `bg.png`。
发布目录 `releases/package/MusicPlayer` 也已放入 HTML、背景和本文。
